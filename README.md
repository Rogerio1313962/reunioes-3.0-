REUNIÕES 3.0 — PRÉVIA 127

Arquivos completos do aplicativo. Publique o conteúdo desta pasta na raiz do repositório GitHub Pages, substituindo os arquivos anteriores (não envie o ZIP fechado).

Ajustes desta versão:
- Toque único num versículo da aba Bíblia projeta imediatamente, sem botões adicionais.
- O versículo tocado fica selecionado em amarelo, um por vez.
- Configurações: engrenagem incorporada à mesma linha do seletor ACF/ARA.
- Controlador abaixo do telão tanto na Bíblia quanto no Cronograma, com três versículos (anterior, atual, próximo).
- Redução do efeito de seleção azul ao tocar no controle.
- Ajustes para aproveitar toda a largura da prévia e manter referências inferiores dentro do quadro.
- Referência opcional com sigla abreviada ACF ou ARA.
- A aba FUNDOS da versão 124 foi preservada.
- Versões dos scripts atualizadas para forçar a atualização do cache.

ATENÇÃO: todos os arquivos do ZIP precisam ser publicados na mesma pasta. Depois da publicação, recarregue o Safari para obter a nova versão. Não foi possível executar teste automatizado de navegador neste ambiente; use como prévia de teste, não em reunião real.

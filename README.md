# REUNIÕES 3.0 — PRÉVIA 27

Cadastro de músicas agrupadas simplificado: sem digitar título ou artista. O título é sugerido a partir do primeiro arquivo MP3; para acrescentar versões, use o conjunto existente. Escolha a pasta tocando em cartões grandes. Adicione manualmente arquivos MP3 nas partes Completa, Trecho, Refrão e Fundo. O sistema não classifica automaticamente o destino pelo nome. É possível escolher vários MP3 em cada parte. Antes de salvar, confirme a lista de arquivos e seus destinos.

Somente arquivos .mp3 são aceitos na importação agrupada. O seletor do iPad pode mostrar outros arquivos, mas o aplicativo impede que sejam salvos. Os arquivos ficam armazenados localmente no navegador do dispositivo.

Atualize os arquivos no repositório GitHub Pages. Caso o Safari apresente versão antiga, atualize a página.
